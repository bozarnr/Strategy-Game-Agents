# Validation Boundary

This repository demonstrates experiment tooling and strategy-agent simulation.
It does not claim that the agents explain real investor behavior or produce a
trading signal.

Current evidence:

- Deterministic simulation only.
- Unit tests for reproducibility, learning updates, regret metrics, and
  loss-aversion behavior.
- No private participant data or raw submissions.

Required before stronger claims:

- Public or anonymized participant trace schema.
- Parameter-fitting protocol with train/test split.
- Goodness-of-fit and counterexample analysis.
- Sensitivity checks for payoff distribution, framing, and sample selection.
